## Источник данных

Учебный датасет: **Coffee Shop Sales** — транзакции вымышленной кофейни Maven Roasters (три точки в Нью-Йорке, ~150 тыс. строк, январь–июнь 2023).

- Первоисточник: [Maven Analytics Data Playground](https://mavenanalytics.io/data-playground/coffee-shop-sales)
- Копия на Kaggle: [ahmedabbas757/coffee-sales](https://www.kaggle.com/datasets/ahmedabbas757/coffee-sales)
- Файл в этом модуле: `Coffee_Sales_Data.csv`
- Лицензия: **Public Domain** — данные свободны для любого использования, атрибуция не обязательна (ссылка на источник — дань уважения авторам).
