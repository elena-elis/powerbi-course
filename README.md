# Power BI Desktop: от данных к дашборду

Учебные материалы к курсу по Power BI Desktop: от первого подключения к данным до оптимизации, безопасности и доставки готового отчёта. 6 основных модулей и 2 бонусных.

[▶ Перейти к курсу на Stepik](ССЫЛКА_НА_КУРС)

## Как скачать материалы

Регистрация на GitHub не требуется:

- чтобы скачать **всё сразу** — нажмите зелёную кнопку **Code → Download ZIP** в верхней части страницы;
- чтобы скачать **отдельный файл** — откройте его по ссылке из урока и нажмите «Download raw file».

## Источники данных

Курс использует открытые учебные датасеты. Все права на исходные данные принадлежат их авторам.

| Модуль | Датасет | Источник | Лицензия |
|---|---|---|---|
| A | Coffee Shop Sales (Maven Roasters) | [Maven Analytics](https://mavenanalytics.io/data-playground/coffee-shop-sales), копия на [Kaggle](https://www.kaggle.com/datasets/ahmedabbas757/coffee-sales) | Public Domain |
| B | IBM HR Analytics Employee Attrition & Performance | [Kaggle — pavansubhasht](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset) | Синтетические данные IBM, свободное учебное использование |
| C | E-commerce Sales Data 2024–2025 | [Kaggle — prince7489](https://www.kaggle.com/datasets/prince7489/e-commerce-sales) | CC0 / Public Domain |
| D | Superstore Sales (`train.csv`) | [Kaggle — rohitsahoo](https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting) | Учебный Superstore (на основе демонстрационных данных Tableau) |
| E | Retail Fashion Boutique Data Sales Analytics 2025 | [Kaggle — pratyushpuri](https://www.kaggle.com/datasets/pratyushpuri/retail-fashion-boutique-data-sales-analytics-2025) | Apache 2.0 (с указанием авторства) |
| F | Superstore Dataset Final | [Kaggle — vivek468](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final) | Учебный Superstore (на основе демонстрационных данных Tableau) |

Датасеты не входят в лицензию курса и используются на условиях их первоисточников. Детали — в README каждого модуля.
